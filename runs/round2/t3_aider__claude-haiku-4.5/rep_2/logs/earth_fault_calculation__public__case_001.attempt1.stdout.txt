## Calculation



**Given data:**

- Sbase = 50 MVA

- Vbase = 13.8 kV

- Z1 = 0.042 + j0.31 pu

- Z2 = 0.045 + j0.29 pu

- Z0 = 0.12 + j0.82 pu

- Zf = 0.04 pu (fault resistance, purely resistive)

- Prefault voltage = 1.0 pu



**Step 1: Calculate Ibase**

```
Ibase = 50 / (√3 × 13.8) = 50 / 23.887 ≈ 2.0936 kA

```


**Step 2: Calculate total impedance**

```
Z_total = Z1 + Z2 + Z0 + 3*Zf

        = (0.042 + j0.31) + (0.045 + j0.29) + (0.12 + j0.82) + 3(0.04)

        = (0.042 + 0.045 + 0.12 + 0.12) + j(0.31 + 0.29 + 0.82)

        = 0.327 + j1.42 pu

```


**Step 3: Calculate magnitude and angle of Z_total**

```
|Z_total| = √(0.327² + 1.42²) = √(0.10693 + 2.0164) = √2.12333 ≈ 1.4572 pu

∠Z_total = arctan(1.42/0.327) ≈ 76.98°

```


**Step 4: Calculate sequence currents (pu)**

```
I1 = I2 = I0 = 1 / Z_total

|I| = 1 / 1.4572 ≈ 0.6867 pu

∠I = -76.98° (negative because we divide by impedance)

```


**Step 5: Convert to kA**

```
|I| = 0.6867 × 2.0936 ≈ 1.4378 kA

∠I = -76.98°

```


**Step 6: Calculate residual current (3*I0)**

```
|3*I0| = 3 × 1.4378 ≈ 4.3134 kA

∠(3*I0) = -76.98°

```
