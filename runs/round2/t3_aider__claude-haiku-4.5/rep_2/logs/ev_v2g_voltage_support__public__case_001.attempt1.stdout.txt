**Objective:** Compute reactive-power commands for EV chargers to support feeder
voltages after reconfiguration.



**Given data:**

- Target voltage: 0.98 pu

- Base voltages: bus_2 = 0.944 pu, bus_3 = 0.952 pu

- Voltage sensitivities: bus_2 = 0.0016 pu/kvar, bus_3 = 0.0012 pu/kvar

- EVs with S-ratings and active power at each bus



**Algorithm:**

1. For each bus, calculate voltage deficit: `target_voltage_pu - 
base_voltage_pu`

2. Calculate required reactive power using sensitivity: `q_required = 
voltage_deficit / q_sensitivity`

3. Calculate aggregate EV inverter capability at each bus using: `q_max = 
sqrt(s_rating² - p²)` for each EV

4. Clip the required reactive power by the aggregate capability

5. Calculate corrected voltage and total absolute reactive effort



**Calculations:**



**Bus 2:**

- Voltage deficit: 0.98 - 0.944 = 0.036 pu

- Q required: 0.036 / 0.0016 = 22.5 kvar

- EVs at bus_2: evse_1 (18 kva, 10 kw) and evse_2 (12 kva, 6 kw)

  - evse_1: q_max = sqrt(18² - 10²) = sqrt(324 - 100) = sqrt(224) ≈ 14.97 kvar

  - evse_2: q_max = sqrt(12² - 6²) = sqrt(144 - 36) = sqrt(108) ≈ 10.39 kvar

  - Aggregate q_max = 14.97 + 10.39 ≈ 25.36 kvar

- Clipped q_dispatch = min(22.5, 25.36) = 22.5 kvar

- Corrected voltage: 0.944 + (22.5 × 0.0016) = 0.944 + 0.036 = 0.98 pu



**Bus 3:**

**Total absolute reactive:** 22.5 + 13.86 = 36.36 kvar
