Let me first understand the formulas from the instructions:
1. Steady-state top-oil rise: `top_oil_rise_rated_k * ((1 + R*K^2)/(1 + R))^x`
2. End-of-step top-oil rise approaches exponentially with time constant 
`oil_time_constant_h`
3. Top-oil temperature = ambient + end-of-step rise
4. Hot-spot temperature = top-oil + `hot_spot_gradient_rated_k * K^y`
5. Relative ageing rate: `2^((hot_spot - 
reference_hot_spot_c)/doubling_interval_k)`

Let me create a Python script to compute this:

```python
import json
import math

# Load data from task.json
with open('task.json', 'r') as f:
    task = json.load(f)

case = task['transformer_thermal_case']

# Extract parameters
initial_top_oil_rise_k = case['initial_top_oil_rise_k']
rated = case['rated']
limits = case['limits']
ageing = case['ageing']
load_steps = case['load_steps']

# Rated parameters
top_oil_rise_rated_k = rated['top_oil_rise_rated_k']
R = rated['loss_ratio_r']
x = rated['oil_exponent_x']
y = rated['winding_exponent_y']
hot_spot_gradient_rated_k = rated['hot_spot_gradient_rated_k']
oil_time_constant_h = rated['oil_time_constant_h']

# Ageing parameters
reference_hot_spot_c = ageing['reference_hot_spot_c']
doubling_interval_k = ageing['doubling_interval_k']
max_hot_spot_c = limits['max_hot_spot_c']

# Initialize results
top_oil_c = {}
hot_spot_c = {}
ageing_rate = {}
total_ageing_hours = 0.0
max_hot_spot = -float('inf')

# Current top-oil rise (starts with initial value)
current_top_oil_rise = initial_top_oil_rise_k

# Process each load step
for step in load_steps:
    step_id = step['id']
    duration_h = step['duration_h']
    ambient_c = step['ambient_c']
    K = step['load_factor_pu']
    
    # Steady-state top-oil rise for this load
    steady_state_rise = top_oil_rise_rated_k * ((1 + R * K**2) / (1 + R))**x
    
    # Exponential approach to steady state
    # theta_final = theta_ss + (theta_initial - theta_ss) * exp(-t/tau)
    # But we want the rise at end of step, so:
    end_rise = steady_state_rise + (current_top_oil_rise - steady_state_rise) * 
math.exp(-duration_h / oil_time_constant_h)
    
    # Top-oil temperature
    top_oil_temp = ambient_c + end_rise
    
    # Hot-spot temperature
    hot_spot_temp = top_oil_temp + hot_spot_gradient_rated_k * (K ** y)
    
    # Relative ageing rate
    ageing = 2 ** ((hot_spot_temp - reference_hot_spot_c) / doubling_interval_k)
    
    # Equivalent ageing for this step
    step_ageing = ageing * duration_h
    
    # Store results
    top_oil_c[step_id] = round(top_oil_temp, 6)
    hot_spot_c[step_id] = round(hot_spot_temp, 6)
    ageing_rate[step_id] = round(ageing, 6)
    
    total_ageing_hours += step_ageing
    max_hot_spot = max(max_hot_spot, hot_spot_temp)
    
    # Update for next step
    current_top_oil_rise = end_rise

# Determine if overload is admissible
overload_admissible = max_hot_spot <= max_hot_spot_c

# Create submission
submission = {
    "top_oil_c": top_oil_c,
    "hot_spot_c": hot_spot_c,
    "ageing_rate": ageing_rate,
    "total_ageing_hours": round(total_ageing_hours, 6),
    "max_hot_spot_c": round(max_hot_spot, 6),
    "overload_admissible": overload_admissible
}

print(json.dumps(submission, indent=2))
```
