**Method (per `calculation_spec`):**
- **Baseline / with-FCI customer-minutes/year:** Σ (annual_fault_rate × customers_interrupted × restoration_minutes), using base durations for baseline and, with FCI, `max(25, base − best reduction from n2/n4)` per section.
- **Customer-interruptions/year:** Σ (annual_fault_rate × customers_interrupted) = 45.8 (unchanged by FCI).
- **SAIDI** = customer-minutes / 320; **CAIDI** = customer-minutes / 45.8; **SAIFI** = 45.8 / 320 = 0.143125.

**Section durations with FCI:** s12→89, s23→52, s24→59, s45→41 min.

**Results:** baseline SAIDI 12.575, CAIDI ~87.86; with FCI SAIDI 10.0525, CAIDI ~70.24; SAIDI improvement 2.5225 min/customer-year, CAIDI improvement ~17.62 min/interruption.
