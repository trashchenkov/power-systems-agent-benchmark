**Method (from the task spec):**
- For each branch: \(y = 1/(r + jx)\); add \(y + jb/2\) to both end-bus diagonals; add \(-y\) to the off-diagonals.
- Shunt at `bus_3`: add \(g + jb = 0 + j0.04\) to that diagonal.
