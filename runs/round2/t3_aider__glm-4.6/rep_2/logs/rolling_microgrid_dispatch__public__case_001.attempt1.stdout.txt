`load_mw(t) = diesel_mw(t) + pv_mw(t) - pv_curtailment_mw(t) + battery_mw(t)`
Where `battery_mw(t)` is positive for discharge and negative for charge.
`shed_mw(t)` must be 0 as per the instructions.

**The State of Charge (SOC) Update Equation:**
`soc_mwh(t+1) = soc_mwh(t) - battery_mw(t) * interval_hours /

`soc_mwh(t+1) = soc_mwh(t) - battery_mw(t) * interval_hours * charge_efficiency`
if `battery_mw(t) < 0` (charging)
Let's simplify this. A common way to model this is:
`soc_mwh(t+1) = soc_mwh(t) - (battery_mw(t) * interval_hours) / eff`
where `eff` is `discharge_efficiency` if `battery_mw(t) > 0` and 
`1/charge_efficiency` if `battery_mw(t) < 0`.
Let's use a more standard formulation:
`Energy_out = battery_mw(t) * interval_hours` if `battery_mw(t) > 0`
`Energy_in = -battery_mw(t) * interval_hours` if `battery_mw(t) < 0`
`soc_mwh(t+1) = soc_mwh(t) - Energy_out / discharge_efficiency + Energy_in * 
charge_efficiency`

**Objective Function:**
