1. **Objective**: Choose a monotonic PV inverter Volt-VAR curve that mitigates 
low-voltage sag and high-voltage swell over a short feeder time series without 
exceeding inverter reactive-power capability.



2. **Hard constraints**:

   - Volt-VAR curve voltage_pu breakpoints must be strictly increasing

   - Volt-VAR curve q_fraction values must be monotonic non-increasing as 
voltage rises

   - Reactive power command at each timestep must stay within inverter 
capability sqrt(kVA² - kW²)

   - Corrected voltage at each timestep must remain within voltage_limits_pu 
(0.95-1.05 pu)



3. **Public inputs**: 3 timesteps with different conditions:

   - t_low: base_voltage=0.94 pu (below min limit), pv_kw=60, inverter_kva=100, 
sensitivity=0.0007

   - t_nom: base_voltage=1.0 pu (nominal), pv_kw=80, inverter_kva=100, 
sensitivity=0.00055

   - t_high: base_voltage=1.07 pu (above max limit), pv_kw=60, inverter_kva=100,
sensitivity=0.0007



4. **Inverter capability**: Q_max = sqrt(kVA² - kW²)

   - t_low: Q_max = sqrt(100² - 60²) = sqrt(10000-3600) = sqrt(6400) = 80 kvar

   - t_nom: Q_max = sqrt(100² - 80²) = sqrt(10000-6400) = sqrt(3600) = 60 kvar

   - t_high: Q_max = sqrt(100² - 60²) = 80 kvar



5. **Voltage correction**: corrected_voltage = base_voltage + sensitivity * 
q_actual

   where q_actual = q_fraction * inverter_kva



6. **Volt-VAR curve**: Need to define points with voltage_pu and q_fraction. For
PV Volt-VAR control:

   - At low voltage: inject reactive power (q_fraction > 0) to raise voltage

   - At high voltage: absorb reactive power (q_fraction < 0) to lower voltage

   - The curve should be monotonic non-increasing (q_fraction decreases as 
voltage increases)



Let me design a curve that:

pu. q = -0.02/0.0007 ≈ -28.57 kvar. q_fraction = -28.57/100 = -0.2857

- Point 1: voltage_pu=0.94, q_fraction=0.2 (injects 20 kvar)
