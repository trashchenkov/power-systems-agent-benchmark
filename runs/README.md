# Benchmark run artifacts

This directory stores the curated artifacts needed to audit the paper's reported
experiments plus local run outputs generated by the benchmark scripts. Public agent
logs are intentionally part of the artifact set: they expose not only the final
benchmark score, but also how each agent behaved while solving the task.

Committed policy:

```text
runs/
  canonical_round1/REPORT.md
  canonical_round1/<agent>-public/summary.json
  canonical_round1/<agent>-public/results.jsonl
  canonical_round1/<agent>-public/submissions/*.json
  canonical_round1/<agent>-public/logs/*.txt
  canonical_round1/<agent>-hidden/summary.json
  extra_models/INDEX.md
  extra_models/<harness>__<model>/summary.json
  extra_models/<harness>__<model>/results.jsonl
  generator_validation/summary.json
  public_baselines/latest/summary.json
  public_baselines/latest/results.jsonl
```

Hidden/held-out per-case artifacts are intentionally not committed: submissions,
evaluator `results.jsonl`, logs, packets, and generated hidden tasks disclose the
case answers. Public logs are committed only after sanitizing machine-specific paths
and private/source-corpus breadcrumbs. Public development smoke runs and regenerated
packet directories are ignored unless deliberately promoted into the curated
structure above.

Use:

```bash
python scripts/run_public_baselines.py --out runs/public_baselines/latest
python scripts/prepare_agent_tasks.py --out runs/agent_packets/public_v0
python scripts/prepare_agent_tasks.py --split hidden --out runs/agent_packets/hidden_101
```

Run command-line agents with `scripts/run_agent_command.py` as described in
`docs/agent_protocol.md`. Before committing new run evidence, check that public
artifacts are sanitized and that held-out artifacts remain aggregate-only.
